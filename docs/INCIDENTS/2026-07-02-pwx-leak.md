## 五、根本原因（5 Whys）

1. **为什么泄露了 pipeworx key？** — Owner 把它粘到了 AI 聊天
2. **为什么 Owner 会粘？** — 因为他没意识到这是聊天而不是私密环境
3. **为什么没意识到？** — 因为"无 auth"宣传让他误以为 key 不重要
4. **为什么误判？** — pipeworx 的"无 auth"宣传 + 免费档 + URL 示例诱导错误范式
5. **为什么会被诱导？** — **v3 没有 SOP 强制要求 key 仅在 .env.local，Owner 不知道有任何限制**

→ **根本原因**：v3 项目从未建立"凭据管理流程"，Owner 借脑记忆 key，借 AI 拼凑 key 字符串。
