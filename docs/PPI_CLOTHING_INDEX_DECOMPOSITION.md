# PPI 服装类指数拆分量价（实操指南）

> **版本**：v1.0 | **日期**：2026-07-01
> **数据源**：国家统计局 PPI 月度数据
> **目的**：从零售额（金额）反推零售量（件数），计算需求弹性

---

## 一、核心原理

```
零售额（名义）= 零售价（P）× 零售量（Q）

已知：零售额（国家统计局月度数据）
已知：PPI 服装类指数（价格变化率）
求解：零售量（Q）

公式：
  实际零售量_t = 名义零售额_t / (PPI_t / 100)
  
  其中 PPI 以某年为基期（=100），剔除价格因素后得到"实际量"
```

## 三、计算步骤（Python 代码）

### 步骤 1：准备数据

```python
import pandas as pd
import numpy as np

# 服装零售额（月度，亿元）- 从国家统计局下载
retail_data = pd.DataFrame({
    'month': ['2025-01','2025-02','2025-03','2025-04','2025-05','2025-06',
              '2025-07','2025-08','2025-09','2025-10','2025-11','2025-12',
              '2026-01','2026-02','2026-03','2026-04','2026-05'],
    'retail_nominal': [1358, 2831, 1325, 1085, 1194, 1236,
                       1183, 1155, 1275, 1341, 1534, 1661,
                       1495, 2831, 1351, 1142, 1251]  # 亿元
})

# PPI 服装类指数（月度，上月=100 环比）- 从国家统计局下载
ppi_data = pd.DataFrame({
    'month': ['2025-01','2025-02','2025-03','2025-04','2025-05','2025-06',
              '2025-07','2025-08','2025-09','2025-10','2025-11','2025-12',
              '2026-01','2026-02','2026-03','2026-04','2026-05'],
    'ppi_mom': [100.0, 100.0, 99.8, 99.9, 100.0, 100.1,
                100.0, 99.9, 100.0, 100.0, 100.0, 100.0,
                100.0, 99.6, 99.9, 99.9, 100.1]  # 上月=100
})
```

### 步骤 2：将环比指数转换为定基指数

```python
# 环比 → 定基（以 2025-01 为基期 = 100）
ppi_data['ppi_index'] = 100.0
for i in range(1, len(ppi_data)):
    ppi_data.loc[i, 'ppi_index'] = (
        ppi_data.loc[i-1, 'ppi_index'] * ppi_data.loc[i, 'ppi_mom'] / 100
    )

# 结果：ppi_index 以 2025-01 = 100 为基期
# 2026-05 的 ppi_index ≈ 99.5（说明价格比 2025-01 降了 0.5%）
```

### 步骤 3：计算实际零售量（平减）

```python
# 合并数据
df = retail_data.merge(ppi_data, on='month')

# 计算实际零售额（剔除价格因素）= 名义零售额 / (PPI/100)
df['retail_real'] = df['retail_nominal'] / (df['ppi_index'] / 100)

# 计算隐含价格（实际量的代理）
# 如果假设 2025-01 的平均单价为 P0，则：
# 实际量_t = 名义额_t / (P0 × PPI_t / 100)
# 但我们不需要知道 P0 的绝对值，只需要变化率

# 计算量的变化率（同比）
df['retail_real_yoy'] = df['retail_real'].pct_change(12) * 100  # 12 个月同比
```

### 步骤 4：计算需求弹性

```python
# 需求弹性 = 量的变化率 / 价格的变化率
# 价格变化率 = (PPI同比 - 100)%

df['ppi_yoy_pct'] = df['ppi_mom'].rolling(12).apply(
    lambda x: (np.prod(x/100) - 1) * 100
)

df['elasticity'] = df['retail_real_yoy'] / df['ppi_yoy_pct']

# 注意：PPI 是出厂价，不是零售价
# 零售价变化 ≈ PPI变化 × 渠道加价系数（通常 1.2-1.5x）
# 更精确的做法：用 CPI 衣着类代替 PPI 作为零售端价格指数
```

## 四、更精确的方法：用 CPI 衣着类代替 PPI

```
PPI 是出厂价（生产端）
CPI 衣着类是零售价（消费端）—— 更适合计算消费者需求弹性

CPI 衣着类指数下载：
https://data.stats.gov.cn/easyquery.htm?cn=A01
→ 月度数据 → CPI → 居民消费价格指数
→ 指标：衣着类

计算方法完全相同，只是把 PPI 换成 CPI：
  实际量_t = 名义零售额_t / (CPI_衣着_t / 100)
  需求弹性 = 实际量变化% / CPI_衣着变化%
```

---

## 五、已有数据的快速估算

```
从搜索结果获取的 PPI 数据：

  2026-01 PPI 衣着同比：-0.7%（即 99.3）
  2026-03 PPI 衣着同比：-1.1%（即 98.9）
  2026-04 PPI 衣着同比：-1.1%（即 98.9）
  2026-05 PPI 衣着环比：100.1（即 +0.1%）

  2026-01~05 服装零售额同比：+7.2%

快速估算弹性：
  价格变化：-1.1%（出厂价降了 1.1%）
  量变化：+7.2% - (-1.1%) = +8.3%（实际量增长）
  
  弹性 = 8.3% / (-1.1%) = -7.5
  
  这个数字异常高，说明：
  1. PPI 衣着类变化太小（仅 -1.1%），分母太小导致弹性爆炸
  2. 零售额增长主要来自量增而非价变
  3. 需要用 CPI 衣着类（变化幅度更大）才能得到合理弹性
```

## 六、结论

| 方法 | 公式 | 优点 | 缺点 |
|------|------|------|------|
| PPI 平减法 | 实际量 = 零售额 / (PPI/100) | 数据免费、月度更新 | PPI 变化太小时弹性失真 |
| CPI 平减法 | 实际量 = 零售额 / (CPI_衣着/100) | 更贴近消费端 | 同样有小变化失真问题 |
| 回归法 | ln(量) = α + β×ln(价) | 统计严谨、置信区间 | 需要足够长的时间序列 |
| 文献取值法 | 学术研究的行业均值 | 简单快速 | 不够精确 |

**推荐**：先用 CPI 衣着类做平减，如果弹性仍失真，改用 2020-2026 年 72 个月的数据做 OLS 回归，得到更稳健的 β 系数。
