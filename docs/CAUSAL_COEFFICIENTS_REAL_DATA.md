| 氨纶 | ¥29,833/吨 | +21.8% | CCFEI（A） |

### 系数推导

```
棉花 → 涤纶（间接联动）：
  原理：棉花和涤纶是替代品，棉花涨价 → 需求转向涤纶 → 涤纶涨价
  2026 数据：棉花 -2.1% vs 涤纶 +17.6%
  结论：2026 年涤纶涨价主因是 PTA（原油）而非棉花替代效应
  传导率：0.1-0.2（弱联动，主要受原油驱动）
  滞后期：2-4 周（替代需求传导）
  可信度：B（缺乏直接因果量化研究）

棉花 → 羊毛（互补品）：
  原理：棉花和羊毛在低端市场有替代关系
  2026 数据：棉花 -2.1% vs 羊毛 +61%
  结论：羊毛涨价与棉花完全独立（澳洲干旱减产）
  传导率：~0（几乎不联动）
  可信度：A（数据明确）

涤纶 → 氨纶（成本联动）：
  原理：氨纶原料 PTMEG 与 PTA 同属石化链
  2026 数据：PTA +18.4% vs 氨纶 +21.8%
  传导率：0.8-0.9（高度联动）
  滞后期：1-2 周
  可信度：A（石化链价格同步性强）
```

## 二、边 ②→③：化纤 → 面料（成本传导）

### 已知数据

| 纱线 | 成本构成 | 棉花占比 | 加工费 | 纱线价 | 同比 |
|------|---------|---------|--------|--------|------|
| 32S 精梳棉 | 棉花+加工 | 72% | ¥6,000 | ¥21,300 | +5% |
| 40S 精梳棉 | 棉花+加工 | 67% | ¥7,500 | ¥22,800 | +5% |
| 32S 普梳棉 | 棉花+加工 | 75% | ¥5,000 | ¥20,300 | +4% |
| POY-DTY | 涤纶+加工 | 88% | ¥1,157 | ¥9,619 | +17.6% |

### 系数推导

```
棉花 → 棉纱：
  传导率 = 棉花在纱线成本中的占比 = 72%（32S精梳）
  即：棉花涨 10%，纱线理论涨 7.2%
  实际：加工费相对固定，传导率 ≈ 0.72
  滞后期：1-2 周（纱厂报价周期）
  可信度：A+（Obsidian 数据）

PTA → 涤纶纱：
  传导率 = PTA 在涤纶成本中的占比 = 88%
  即：PTA 涨 10%，涤纶纱理论涨 8.8%
  实际：加工费稳定（POY-DTY 加工费 ¥1,157），传导率 ≈ 0.88
  滞后期：1 周（化纤厂报价周期）
  可信度：A+（Obsidian 数据）

纱线 → 面料（针织）：
  原理：面料成本 = 纱线成本 + 织造加工费（含染整）
  针织面料：纱线占面料成本 60-70%
  传导率：0.6-0.7
  滞后期：2-4 周（面料厂报价周期）
  可信度：B（行业经验值，缺乏精确量化）
```

|------|-----------------|------|------------|------|

| 之禾 | 出出厂价×5-8 | 5-8x | 20-30% | 行业对标（B） |

### 系数推导

```
出厂价 → 零售价：
  倍率 = 零售价 / 出厂价
  优衣库：3-4 倍（低倍率，高周转）
  ZARA：4-6 倍（中倍率）
  高端品牌：5-8 倍（高倍率，高毛利）
  
  传导率 = 1/倍率 = 出厂价在零售价中的占比
  优衣库：25-33%
  ZARA：17-25%
  高端：13-20%
  
  即：出厂价涨 10%
  优衣库零售涨 2.5-3.3%
  ZARA 零售涨 1.7-2.5%
  高端零售涨 1.3-2.0%
  
  滞后期：3-6 月（品牌定价周期，含订货会→生产→上架）
  放大系数：0.5（品牌吸收大部分成本上涨）
  可信度：A（年报推算）

## 五、边 ⑥→⑦：品牌 → 渠道（零售→消费者）

### 已知数据

| 渠道 | 渠道费率 | 退货率 | 折扣率 | 权源 |
|------|---------|--------|--------|------|
| 天猫 | 5-8% | 20-30% | 10-20% | 行业（A） |
| 抖音 | 15-25% | 30-50% | 20-40% | 蝉妈妈（B） |
| 线下门店 | 25-35% | 5-10% | 10-30% | 赢商网（B） |
| 得物/唯品 | 10-15% | 10-20% | 30-50% | 行业（B） |

### 系数推导

```
零售价 → 消费者到手价：
  消费者到手价 = 零售价 × (1 - 折扣率) × (1 + 退货损失)
  
  天猫：到手价 ≈ 零售价 × 0.7 × 0.8 = 零售价 × 0.56
  抖音：到手价 ≈ 零售价 × 0.6 × 0.7 = 零售价 × 0.42
  线下：到手价 ≈ 零售价 × 0.8 × 0.95 = 零售价 × 0.76
  
  传导率：零售价变动对消费者感知的传导
  天猫：0.56（消费者只感知到 56% 的零售价变动）
  抖音：0.42（促销驱动，消费者对原价不敏感）
  线下：0.76（消费者对原价较敏感）
  
  滞后期：即时（价格标签实时可见）
  放大系数：1.5-2.0（促销放大价格敏感度）
  可信度：B（行业经验值）
```

```

  服装需求价格弹性：-0.5 到 -0.8（非必需品，弹性中等）
  即：价格涨 10%，需求降 5-8%
  
  传导率：0.5-0.8（价格弹性）
  滞后期：即时-1 月（冲动购买 vs 计划购买）
  放大系数：2.0（社交媒体放大价格敏感度）
  可信度：B（经济学经验值，缺乏服装行业精确数据）

> **核心结论**：
> 1. Obsidian 已有的数据能支撑 ②→③→⑤ 三条边的精确系数（纱线成本拆分 + 年报数据）
> 2. ⑤→⑥（制造→品牌）的系数从品牌倍率反推，可信度 A
> 3. ⑦→⑧（渠道→消费者）的弹性系数最弱，需补消费调研数据
> 4. 所有系数都是**动态的**，需要从实时数据中持续学习更新
