# 加工费独立建模（能源 + 人工分离）

> **目的**：将加工费从"固定值"拆分为能源和人工两个独立变量
> **数据源**：Obsidian 针织成本模型 + 国统局 PPI 月度数据 + ILO 工资数据

---

## 一、加工费成本拆解（基于 Obsidian T 恤模型）

### 1.1 一件 T 恤 FOB ¥15 的成本构成

| 成本项 | 金额 ¥/件 | 占比 | 类型 | 年化通胀 |
|--------|----------|------|------|---------|
| 面料 | 3.20 | 21.3% | 原料 | +8% |
| 辅料 | 0.80 | 5.3% | 原料 | 持平 |
| **裁剪+缝制人工** | **5.00** | **33.3%** | **人工** | **+5%** |
| 后整理 | 0.50 | 3.3% | 加工 | 持平 |
| **水电气** | **0.40** | **2.7%** | **能源** | **+3%** |
| 管理费用 | 1.50 | 10.0% | 固定 | 持平 |
| 折旧 | 0.60 | 4.0% | 固定 | 持平 |
| 工厂利润 | 3.00 | 20.0% | 利润 | — |
| **FOB** | **¥15.00** | **100%** | — | — |

### 1.2 加工费定义（不含原料）

```
加工费 = 人工 + 能源 + 后整理 + 管理 + 折旧
       = 5.00 + 0.40 + 0.50 + 1.50 + 0.60
       = ¥8.00/件

其中：
  人工占比 = 5.00 / 8.00 = 62.5%
  能源占比 = 0.40 / 8.00 = 5.0%
  后整理占比 = 0.50 / 8.00 = 6.3%
  管理+折旧占比 = 2.10 / 8.00 = 26.3%
```

## 二、能源成本模型（独立变量）

### 2.1 能源成本构成

```
能源成本 = 电力 + 蒸汽 + 燃气
         = 纺纱用电 + 织造用电 + 染整蒸汽 + 后整理燃气
```

### 2.2 PPI 能源指数（国统局月度数据）

| 月份 | PPI 燃料动力类（购进价同比） | PPI 电力热力（出厂价同比） | 权源 |
|------|--------------------------|--------------------------|------|
| 2026-01 | — | -3.4% | 国统局 |
| 2026-02 | — | -3.4% | 国统局 |
| 2026-03 | -3.8% | -3.8% | 国统局（A+） |
| 2026-04 | **+4.4%** | -4.2% | 国统局（A+） |
| 2026-05 | **+10.0%** | -4.4% | 国统局（A+） |

**关键发现**：
- PPI 燃料动力（购进价）2026-05 同比 +10.0%（原油上涨驱动）
- PPI 电力热力（出厂价）持续为负（-3.8% ~ -4.4%）（电网定价稳定）
- **能源成本对纺织厂的影响 = 电力（稳定）+ 蒸汽/燃气（随油价波动）**

### 2.3 能源成本计算公式

```yaml
# 能源成本模型
energy_cost_model:
  # 基础能源（电力）—— 相对稳定
  electricity:
    base: 0.25  # ¥0.25/件（占能源成本 62.5%）
    inflation: "PPI 电力热力（出厂价同比）"
    2026_value: -0.044  # -4.4%
    note: "电网定价受政策管控，波动小"
    
  # 热能（蒸汽+燃气）—— 随油价波动
  thermal:
    base: 0.15  # ¥0.15/件（占能源成本 37.5%）
    inflation: "PPI 燃料动力类（购进价同比）"
    2026_value: +0.10  # +10.0%
    note: "蒸汽/燃气价格与原油高度联动"
    
  # 能源总成本
  total:
    formula: "electricity × (1 + PPI_电力) + thermal × (1 + PPI_燃料)"
    2026_calc: "0.25 × (1 - 0.044) + 0.15 × (1 + 0.10) = 0.239 + 0.165 = ¥0.404"
    vs_base: "¥0.40 → ¥0.404（+1.0%）"
    note: "电力降价抵消了燃料涨价，能源总成本几乎持平"
```

### 2.4 能源成本敏感性分析

| 情景 | PPI 燃料 | PPI 电力 | 能源成本/件 | 变化 |
|------|---------|---------|-----------|------|
| 基准（2026-05） | +10.0% | -4.4% | ¥0.404 | +1.0% |
| 油价暴涨（+20%） | +20.0% | -4.4% | ¥0.419 | +4.8% |
| 油价暴跌（-10%） | -10.0% | -4.4% | ¥0.371 | -7.3% |
| 电价改革（+5%） | +10.0% | +5.0% | ¥0.431 | +7.8% |
| 极端：油价+20%+电价+5% | +20.0% | +5.0% | ¥0.446 | +11.5% |

**结论**：能源成本对 FOB 的影响 = 0.40/15.00 = **2.7%**。即使能源涨 20%，FOB 也只涨 0.6%。能源不是主要矛盾。

## 三、人工成本模型（独立变量）

### 3.1 人工成本构成

```
人工成本 = 裁剪缝制 + 后整理检验 + 管理摊销
         = 基本工资 + 加班费 + 社保 + 福利
```

### 3.2 工资数据（Obsidian + ILO）

| 数据项 | 数值 | 来源 |
|--------|------|------|
| 长三角时薪 | ¥30-35/小时 | 行业（B） |
| 月最低工资（中国） | ¥2,690-3,500 | ILO（A） |
| 时薪（USD） | $3.5-4.5 | ILO（A） |
| 年涨幅 | +5% | 行业共识（A） |
| 越南时薪 | $1.2-1.8 | ILO（A） |
| 孟加拉时薪 | $0.5-0.8 | ILO（A） |

### 3.3 人工成本计算公式

```yaml
# 人工成本模型
labor_cost_model:
  # 基础人工（裁剪+缝制）
  sewing:
    base: 5.00  # ¥5.00/件（FOB 的 33.3%）
    hourly_rate: 32.5  # ¥32.5/小时（长三角中位数）
    pieces_per_hour: 15  # 件/小时（熟练工）
    inflation: "年涨 5%（行业共识）"
    2026_value: 5.00 × 1.05 = ¥5.25
    
  # 后整理人工
  finishing:
    base: 0.50  # ¥0.50/件
    inflation: "年涨 5%"
    2026_value: 0.50 × 1.05 = ¥0.525
    
  # 管理费用（含管理人员工资）
  management:
    base: 1.50  # ¥1.50/件
    inflation: "年涨 3%（管理岗涨幅低于产线）"
    2026_value: 1.50 × 1.03 = ¥1.545
    
  # 人工总成本
  total:
    formula: "sewing × (1 + 5%) + finishing × (1 + 5%) + management × (1 + 3%)"
    2026_calc: "5.25 + 0.525 + 1.545 = ¥7.32"
    vs_base: "¥7.00 → ¥7.32（+4.6%）"
    note: "人工成本年涨 4.6%，与行业共识 5% 基本一致"
```

### 3.4 人工成本敏感性分析

| 情景 | 工资涨幅 | 人工成本/件 | 变化 | FOB 影响 |
|------|---------|-----------|------|---------|
| 基准（2026） | +5% | ¥7.32 | +4.6% | +2.1% |
| 最低工资上调（+8%） | +8% | ¥7.56 | +8.0% | +3.7% |
| 自动化替代（-10%） | -10% | ¥6.30 | -10.0% | -4.7% |
| 极端：工资+8%+自动化-10% | -2% | ¥6.86 | -2.0% | -0.9% |

**结论**：人工成本对 FOB 的影响 = 7.00/15.00 = **46.7%**。人工是加工费的**最大变量**。

## 四、完整加工费模型（能源 + 人工分离）

### 4.1 加工费公式

```
加工费(t) = 人工(t) + 能源(t) + 后整理(t) + 管理(t) + 折旧

其中：
  人工(t) = 人工(t-1) × (1 + 工资通胀率)
  能源(t) = 电力(t) + 热能(t)
           = 电力基础 × (1 + PPI电力) + 热能基础 × (1 + PPI燃料)
  后整理(t) = 后整理(t-1) × (1 + 人工通胀率)
  管理(t) = 管理(t-1) × (1 + 3%)
  折旧(t) = 固定值（设备已购，不随通胀变）
```

### 4.2 2026 年加工费预测

| 成本项 | 2025 基准 | 2026 预测 | 变化 | 驱动因子 |
|--------|----------|----------|------|---------|
| 人工（裁剪缝制） | ¥5.00 | ¥5.25 | +5.0% | 工资年涨 5% |
| 后整理 | ¥0.50 | ¥0.525 | +5.0% | 同人工 |
| 电力 | ¥0.25 | ¥0.239 | -4.4% | PPI 电力 -4.4% |
| 热能 | ¥0.15 | ¥0.165 | +10.0% | PPI 燃料 +10% |
| 管理 | ¥1.50 | ¥1.545 | +3.0% | 管理岗通胀 |
| 折旧 | ¥0.60 | ¥0.600 | 0% | 固定 |
| **加工费合计** | **¥8.00** | **¥8.32** | **+4.0%** | — |
| **能源占加工费** | **5.0%** | **4.9%** | — | 能源不是主矛盾 |
| **人工占加工费** | **62.5%** | **63.4%** | — | 人工是主矛盾 |

### 4.3 加工费对 FOB 的传导

```
FOB = 原料成本 + 加工费 + 工厂利润

2025 FOB = ¥15.00
  原料：¥4.00（26.7%）
  加工费：¥8.00（53.3%）
  利润：¥3.00（20.0%）

2026 FOB 预测：
  原料：¥4.00 × (1 + 原料通胀率)
  加工费：¥8.32（+4.0%）
  利润：¥3.00（假设不变）
  
  如果原料涨 10%：
    FOB = 4.00 × 1.10 + 8.32 + 3.00 = ¥15.72（+4.8%）
    
  如果人工涨 8%：
    FOB = 4.00 + 8.32 × (1 + 8%/加工费中人工占比) + 3.00
        = 4.00 + 8.32 × (1 + 8% × 63.4%) + 3.00
        = 4.00 + 8.74 + 3.00 = ¥15.74（+4.9%）
```
