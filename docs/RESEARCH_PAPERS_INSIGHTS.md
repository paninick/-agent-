# 研究论文核心发现（用于验证 v3 模型）

> **日期**：2026-07-02
> **目的**：从学术论文中提取可验证的系数和机制，补充到 v3 传导模型

---

## 一、东方证券：现实世界的价格传导模型（2026-03-16）

**核心发现**：
- 上游传导能力最强，中游次之，下游最差
- 成本率 > 70%，但传导有"摩擦"
- 2023-2025 供需格局恶化，传导难度加大
- 布油每涨 1%，PPI 上涨 0.041-0.083%

**与 v3 模型的关系**：
- 证实了我们的传导率衰减逻辑
- 提供了原油→PPI 的传导系数（0.041-0.083）
- "涨上游不涨下游" = 我们的"品牌吸收 95%"

## 二、成本加成与价格传递：溢出效应还是吸收效应（2024）

**核心发现**：
- 成本加成定价中，溢出效应和吸收效应同时存在
- 价格传递具有非对称性

**与 v3 模型的关系**：
- 证实了我们的非对称传导率（涨 0.068 / 跌 0.025）
- 为"品牌吸收"提供了理论基础

## 三、奢侈品价格构成分析（2026-06-24）

**核心数据**：
- 原材料成本仅占售价 5%-10%
- 人工成本占比不足 4%
- 品牌营销运营成本占 70%-80%
- 品牌附加值占定价 55%

**与 v3 模型的关系**：
- 优衣库：原料占 FOB 26.7%（vs 奢侈品 5-10%）
- 优衣库：品牌吸收 95%（vs 奢侈品 90%+）
- 证实了品牌是最大的"成本吸收器"

---

## 四、服装行业供需态势分析（2026-06-08）

**核心发现**：
- 需求弹性在当前经济环境下被放大
- 消费者更倾向于在折扣季购买
- 边际消费倾向(MPC)下降（61.5% 倾向储蓄）
- 老龄化 + Z 世代 = 消费结构分化

**与 v3 模型的关系**：
- 解释了为什么需求弹性 -6.87 远高于文献值 -0.50
- 原因：经济下行 + 储蓄偏好 + 消费降级
- 模型需要加入"经济周期"作为控制变量

## 五、价格传导与产量分析（66 页）

**核心框架**：
- 传导机制：水平传导 + 时间延迟 + 黏性效应
- 非对称性：涨快跌慢（与我们一致）
- 市场结构：竞争程度决定传导速度
- 产能弹性：产能约束放大或缩小传导

**与 v3 模型的关系**：
- 为传导引擎提供了完整的理论框架
- "黏性效应" = 我们的非对称传导率
- "产能弹性" = 可以加入到模型中
