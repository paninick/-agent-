## 二、REGRESSION_RESULTS 的关键发现（推翻原有假设）

REGRESSION_RESULTS.md 用**国统局 2024-07 ~ 2026-05 月度真实数据**做了回归，核心结论如下：

### 发现 1：PPI→CPI 传导率只有 0.07（不是 0.30–0.50）

| | 原假设 | 实测回归值 | 差距 |
|--|------|-----------|------|
| PPI 纺织 → CPI 衣着 | 0.30–0.50 | **0.068**（p=0.401，不显著） | **缩小 4–7 倍** |

**含义**：工厂出厂价涨 10%，零售价只涨 0.68%。成本传导在品牌这一层被大量吸收（折扣、利润率压缩、促销活动）。

**论证支撑**：与"面料→成衣（传导率 0.6）→品牌零售（倍率 3–8 倍，传导率 0.13–0.33）"的链式乘积一致：
```
面料涨 10% × 0.6 × 0.25 = 零售涨 1.5%
PPI 纺织涨 10% × 0.07 = CPI 衣着涨 0.68%
```
两个估算在同一数量级，方向一致。✅ 论证自洽。

---

### 发现 2：需求弹性 -6.87（不是 -0.50）——但模型有缺陷

| | 原假设 | 实测回归值 | 问题 |
|--|------|-----------|------|
| CPI 衣着 → 零售弹性 | -0.50 | **-6.87**（p=0.012，显著）| **模型遗漏收入效应** |

**为什么 -6.87 不可信**：
- 2025 年 CPI 衣着 +1.5% → 零售额 +2.8%（同向上涨！）
- 如果弹性真是 -6.87，涨价 1.5% 应导致需求降 10.3%，而实际是增加
- 原因：回归未控制**人均可支配收入**（2025 年增长约 6%），收入效应掩盖了价格弹性

**改进方向**：
```
正确模型：
  ln(零售量) = α + β·ln(CPI衣着) + γ·ln(人均可支配收入) + ε
              β = 价格弹性    γ = 收入弹性
  
  需要同时控制：
    - 季节哑变量（春节/双11）
    - 疫情异常值（剔除 2020Q1–2021Q2）
    - 时间趋势（消费升级趋势项）
```

**当前最佳估计**：区间保留 [-0.5, -0.8]（中国服装需求弹性经济学经验值），待改进模型后更新。

---

### 发现 3：能源传导几乎为零（验证加工费模型）

PPI 燃料涨 10% → PPI 纺织涨 -0.2%。与 PROCESSING_COST_MODEL.md 的结论一致：
- 能源占 FOB 仅 2.7%，人工占 46.7%
- **人工才是加工费的核心变量，能源可以忽略**

## 三、越南数据的颠覆性发现（基于 Comtrade 实测）

来自 20_REAL_DATA_INSIGHTS.md（UN Comtrade 2023 实测）：

### 3.1 棉花传导率被高估

```
原假设：越南棉花依赖中国 → 中国棉花涨价直接传导越南
实测：越南棉花 75% 来自印度/澳大利亚/巴西/美国，只有 25.1% 来自中国

修正后的传导：
  中国棉花涨 10% → 越南棉纱成本涨 10% × 25.1% = 2.5%
  而非原先假设的 10%
```

### 3.2 功能性面料是真正的依赖（不是棉花）

```
HS6001 绒头织物：越南进口 87.8% 来自中国 ← 接近垄断
HS6004 弹性针织：68.7% 来自中国 ← 关键品类
HS60 整体：    66.1% 来自中国

结论：越南工厂的命脉是功能性面料，不是棉花
中国面料涨价 10% → 越南成衣成本涨 10% × 66.1% × 45% ≈ 3.0%
```

这个数据直接修正了边④→⑤（面料→成衣）在越南场景下的传导率计算。

## 七、关键论证结论

1. **7 条边≠7 条空白**。基于 Obsidian 盘点，实际只有 2 条是真空白（⑧→⑨ 和 ⑨→①），其余 5 条都有初步系数，需要的是验证和精化，不是从零开始。

2. **REGRESSION_RESULTS 是关键转折**。PPI→CPI 传导率 0.07 这个实测数据比所有文献值都更有说服力，直接证明了"品牌溢价层吸收成本"的论断。整个 DAG 的传导链式计算现在有了实测支撑。

3. **弹性系数 -6.87 是警示，不是结论**。它提示了模型存在遗漏变量偏误，而不是弹性真的这么大。需要用控制变量的改进模型重跑。

4. **P0 行动只需 1 件事**：富泉内部 BOM 导出。这是唯一一个真正能提升系数精度、且零成本、零外部依赖的行动。

5. **越南场景的传导率需单独建模**：由于越南棉花对中国依赖度只有 25.1%，用"中国棉花涨 10%"直接推"越南工厂成本涨 7.2%"是错的——正确计算是 10% × 25.1% × 棉花在越南成本占比。
