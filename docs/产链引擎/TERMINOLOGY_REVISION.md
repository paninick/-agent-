## 一、原词 / 替换词表

| 原词 | 替换词 | 替换理由 |
|---|---|---|
| 因果推导 | 传导分析 / 关联传导分析 | 因果关系在产业链中多为相关性传导，非严格因果 |
| 因果网络 | 传导网络 / 关联图谱 | 节点间关系为数据驱动关联，非因果链 |
| 世界模型 | 产业链关联图谱 | 避免营销化表述 |
| 真实性验证 | 信源可靠性验证 | 验证对象是信源，不是数据本身 |
| 真相分数 / truth score | 规则置信度 / confidenceScore | 分数反映规则一致性，不是真值 |
| 56 源 | 当前 registry 23 源 | 旧表述与现状不符 |
| 颠覆性发现 | 关键发现 | 避免营销化表述 |
| 革命性升级 | 重要升级 | 避免营销化表述 |
