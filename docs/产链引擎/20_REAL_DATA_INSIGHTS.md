```
──────────────────────────────────────────────────────────────
来源: Comtrade 实测 2023
```

### 1.2 关键发现：越南棉花不依赖中国

```
传统假设: 越南作为亚洲成衣大国，棉花应该也依赖中国
实测结果: 越南棉花 75% 来自中国以外（印度/澳大利亚/巴西/美国）

含义:
  - 棉花涨价对越南工厂的实际传导率 = 25% × 中国棉花涨价率
  - 越南棉纺纱线涨价受 Cotlook 国际棉价影响更大
  - 中国 vs 越南的成本传导差异被低估
```

### 1.3 功能性面料才是越南的命脉

```
HS60 6 位细分 × 中国占比 (越南进口):
  HS6001 绒头织物: 87.8%  ← 接近垄断
  HS6004 弹性针织: 68.7%  ← 关键品类
  HS6006 其他宽幅: 61.4%
  HS6005 经编: 62.5%
  HS6002 窄幅: 64.4%
  HS6003 窄幅其他: 57.0%

中国 HS6001 涨价 8% 的传导:
  越南 HS6001 成本涨幅 = 8% × 87.8% = 7.0% ← 接近全额传导！
  
中国 HS6004 涨价 8% 的传导:
  越南 HS6004 成本涨幅 = 8% × 68.7% = 5.5%
  
结论: 越南面料涨价的关键驱动是功能性面料，不是棉花
```

## 五、产业链传导关系（核心逻辑）

### 5.1 棉花涨价传导链

```
棉花期货 +12% (ICE/FRED)
  ↓
[传导率 70-80% 历史拟合]
  ↓
中国 HS60 面料出口均价 +8-10%
  ↓
越南进口面料成本（66.1% 来自中国）
  ↓
越南 HS60 实际成本涨幅 ≈ 8% × 66.1% = 5.3%
  ↓
越南 HS61 FOB 影响 ≈ 5.3% × 45% (面料占 FOB) = 2.4%
  ↓
品牌采购决策:
  - 优衣库: 吸收成本 + 自营涨价（价格策略稳健）
  - H&M: 压供应商（成本敏感）
  - Temu: 涨价转嫁消费者（薄利多销）
```

### 5.2 关税传导链

```
美国对中国加 25% 关税 (现状)
  ↓
中国对美 HS61 出口竞争力下降
  ↓
越南 HS61 对美出口（53% 集中度）受益
  ↓
越南工厂产能利用率上升
  ↓
越南工厂面料需求上升
  ↓
中国 HS60 面料对越出口增加
  ↓
中国面料厂反而受益于美国关税（间接渠道）
  
意外发现: 美国对华关税短期对中国面料厂有正向影响！
```

### 5.3 品牌库存传导链

```
优衣库 DIO > 95 天（警戒线）
  ↓
[历史规律：4 次 DIO 超 95 天中 3 次砍单 8-15%]
  ↓
下季度优衣库采购量下降
  ↓
中国/越南 Tier-1 供应商受影响
  ↓
中小工厂可能丢订单
  ↓
新供应商（孟加拉/中美洲）获得机会
  
可监控指标:
  - 优衣库每季 DIO
  - 优衣库折扣率（库存压力信号）
  - 优衣库供应商名单变化
  - 中国对日 HS61 出口（提前 3-6 月）
```

## 六、市场结构性结论

### 6.1 "亚洲四小龙"的真实分工

```
中国: 全球面料 + 部分成衣（21% 美国市场）
越南: 全球成衣（17% 美国市场） + 需要进口面料
孟加拉: 欧洲成衣主力（美国 5%） + 低成本优势
柬埔寨: 越南补充（5% 美国市场）
印尼: 东盟替代选项（5% 美国市场）
```

### 6.2 "中美洲四国"的近岸生产崛起

```
洪都拉斯 / 尼加拉瓜 / 萨尔瓦多 / 危地马拉:
  - 受益 USMCA 零关税
  - T 恤市场已被它们主导（36% 份额）
  - 交期 1-2 周（海运 vs 亚洲 30 天）
  - 适合快时尚和补单

对中国启示:
  - 基础 T 恤已经被近岸生产分流
  - 中国优势在毛衣/功能性服装
  - 越南在追近中国在毛衣的份额
```

### 6.3 越南 vs 孟加拉 vs 印尼的差异化定位

```
越南: 
  - 中等成本 + 灵活交期 + 接近中国面料供应链
  - 强项: 毛衣/功能性/中高端
  - 弱项: 基础 T 恤（成本不如中美洲/孟加拉）

孟加拉:
  - 最低成本 + 长交期 + 欧洲订单传统
  - 强项: 基础款/大批量/欧洲市场
  - 弱项: 美国份额小（5%）/灵活性差

印尼:
  - 中等成本 + 服装传统
  - 强项: 穆斯林服装 / 印尼本土市场
  - 美国市场份额: 5%（60% 集中度）
  - 弱项: 产能规模
```
