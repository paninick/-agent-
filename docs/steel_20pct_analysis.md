# 钢材涨价 20% 跨链影响分析

> **日期**：2026-07-01
> **钢材**：螺纹钢 ¥3,230/吨（2026-04 华东）
> **传导路径**：钢材 → 设备折旧 / 厂房成本 / 物流成本 → 服装制造

---

## 一、钢材在产业链中的位置

```
主链（服装）：
  ①棉花 → ②化纤 → ③面料 → ④设计 → ⑤制造 → ⑥品牌 → ⑦渠道 → ⑧消费者

辅链（钢材）：
  钢材 ──→ ⑤制造（设备折旧）
  钢材 ──→ ⑤制造（厂房/仓库建设）
  钢材 ──→ ⑩物流（运输设备）
  钢材 ──→ ②化纤（化工设备）
```

### 钢材影响的具体环节

| 环节 | 影响方式 | 占成本比 | 传导路径 |
|------|---------|---------|---------|
| ⑤制造-设备折旧 | 缝纫机/裁床/整烫设备 | 4.0% | 钢材→设备价格→折旧 |
| ⑤制造-厂房建设 | 厂房钢结构/仓库 | 长期摊销 | 钢材→建筑成本→折旧 |

## 二、传导计算

### 2.1 设备折旧传导

```
钢材涨 20% → 设备价格上涨 X% → 折旧成本上涨 X%

设备成本构成：
  钢材占比：~30-40%（缝纫机机架、裁床框架）
  电机/电子：~40-50%
  其他：~10-20%

假设钢材占设备成本 35%：
  钢材涨 20% → 设备涨 20% × 35% = 7.0%
  设备折旧 = ¥0.60/件（基准）
  新折旧 = ¥0.60 × 1.07 = ¥0.642
  变化 = +¥0.042/件
  占 FOB 比 = 0.042/15.00 = 0.28%
```

### 2.2 厂房/仓库传导

```
钢材涨 20% → 钢结构建筑成本上涨

但厂房已经建好（沉没成本），
钢材涨价只影响：
  1. 新建厂房/仓库的成本（长期摊销）
  2. 现有厂房的维修成本

对当前生产的影响：几乎为零
对扩张计划的影响：新建成本 +7%
```

### 2.3 物流成本传导

```
钢材涨 20% → 车辆/集装箱价格上涨

但车辆已经购买（沉没成本），
钢材涨价只影响：
  1. 新购车辆的成本
  2. 租金（可能被物流商转嫁）

对当前物流的影响：间接，滞后 6-12 月
```

### 2.4 化纤设备传导

```
钢材涨 20% → 化工设备价格上涨 → 化纤成本间接影响

化纤设备成本构成：
  钢材/金属：~40%
  专利/技术：~30%
  安装调试：~30%

钢材涨 20% → 设备涨 20% × 40% = 8.0%
但化纤设备折旧分摊到每吨化纤，影响极小
```

## 三、综合计算

### 3.1 对针织厂 FOB 的影响

| 成本项 | 基准 | 钢材+20%后 | 变化 | 占FOB |
|--------|------|-----------|------|-------|
| 设备折旧 | ¥0.60 | ¥0.642 | +¥0.042 | +0.28% |
| 厂房摊销 | ¥0.00 | ¥0.00 | 无影响 | 0% |
| 物流间接 | ¥0.00 | ¥0.00 | 滞后影响 | ~0% |
| 化纤间接 | ¥0.00 | ¥0.00 | 可忽略 | ~0% |
| **合计** | **¥0.60** | **¥0.642** | **+¥0.042** | **+0.28%** |

### 3.2 传导路径

```
钢材 +20%
  ├─→ 设备折旧 +7.0% → FOB +0.28%（直接，即时）
  ├─→ 厂房维修 +? → FOB +~0%（间接，长期）
  ├─→ 物流成本 +? → FOB +~0%（间接，滞后6-12月）
  └─→ 化纤设备 +8.0% → 化纤成本 +~0.1%（间接，可忽略）

  总影响：FOB +0.28%
  对比棉花+20%的影响：FOB +3.9%
  
  钢材影响 = 棉花影响的 7.2%
```

```
钢材 +20% → 车辆/集装箱 +7% → 运费 +?%
```

```
影响：如果有扩张计划，新建成本增加
对当前生产：无影响（厂房已建成）
```

## 六、传导引擎扩展（钢材模块）

```python
# 钢材传导模块（新增）
class SteelTransmission:
    """钢材→服装制造传导"""
    
    def __init__(self):
        self.steel_base = 3230  # ¥/吨
        self.equipment_steel_share = 0.35  # 设备中钢材占比
        self.depreciation_base = 0.60  # 折旧基准 ¥/件
        self.fob_base = 15.00
    
    def propagate(self, steel_change_pct):
        # 设备折旧传导
        equipment_change = steel_change_pct * self.equipment_steel_share
        depreciation_new = self.depreciation_base * (1 + equipment_change)
        fob_impact = (depreciation_new - self.depreciation_base) / self.fob_base
        
        return {
            'steel_change': steel_change_pct,
            'equipment_change': equipment_change,
            'depreciation_new': depreciation_new,
            'fob_impact': fob_impact,
            'fob_impact_pct': fob_impact * 100,
        }
```
