## 一、因果链条全景（9 环节 DAG）

```
① 农业（棉花/羊毛/丝麻）
  │ USDA WASDE + 中国棉花协会
  │ 因果关系：产量 ↓ → 价格 ↑ → 纱线成本 ↑
  ▼
② 化学纤维（涤纶/尼龙/氨纶/粘胶）
  │ PTA/MEG 期货 + CCFEI + 上市公司季报
  │ 因象关系：原油 → PTA → 涤纶长丝 → 面料成本
  ▼
③ 面料织造与染整（针织/梭织/染色/后整）
  │ 柯桥指数 + 盛泽指数 + 印染协会
  │ 因象关系：纱线价 + 加工费 → 面料出厂价
  ▼
④ 设计开发（趋势/BOM/打版/样衣）
  │ WGSN + Pantone + 设计师人才
  │ 因象关系：趋势 → 款式 → BOM → 成本估算
  ▼
⑤ 生产制造（裁剪/缝制/品质/交期）
  │ 申洲/晶苑年报 + 中国服装协会 + ILO
  │ 因象关系：面料 + 人工 + 能源 → 成衣出厂价
  ▼
⑥ 品牌运营（定位/定价/营销/内容）
  │ LVMH/迅销/H&M 年报 + 天猫/抖音 GMV
  │ 因象关系：成衣成本 + 品牌溢价 → 零售价
  ▼
⑦ 渠道与零售（批发/电商/直播/门店）
  │ 阿里/京东季报 + 蝉妈妈 + 赢商网
  │ 因象关系：零售价 × 渠道费 → 消费者到手价
  ▼
⑧ 消费者行为（购买/穿着/评价/退货）
  │ 国家统计局 + 麦肯锡 + 小红书
  │ 因象关系：消费信心 → 购买意愿 → 零售表现
  ▼
⑨ 回收与循环经济（废旧/再生/Vintage）
  │ Textile Exchange + GRS 认证 + ThredUp
  │ 因象关系：废旧量 → 再生纤维供给 → 原料成本（回到环节①）
```

## 三、因果链条上的工作流（跨环节联动）

### 3.1 全链路价格传导追踪

```
触发：棉花价格变化 >3%

追踪路径：
  ①→②→③→④→⑤→⑥→⑦→⑧
  
  每个节点的 Skills 调用：
  ① fetch_world_bank（棉花价格）
  ② fetch_pta_futures（化纤价格联动）
  ③ fetch_kqindex（面料价格联动）
  ④ websearch_趋势（品牌是否调整选款）
  ⑤ causal_dag（工厂成本传导计算）
  ⑥ fetch_hkex_pdf（品牌财报是否反映成本压力）
  ⑦ fetch_tmall_gmv（零售价是否变化）
  ⑧ websearch_消费者（消费者是否接受涨价）
  
  输出：整条链的价格传导报告 + 各节点影响评估
  写入：Obsidian/_产业链图谱/价格传导/{date}.md
```

### 3.2 订单波动全链路影响

```
触发：fetch_comtrade_flow 发现某品牌进口下降 >10%

追踪路径：
  ⑪品牌→⑤制造→④设计→③面料→②化纤→①农业
  
  ⑧ fetch_hkex_pdf（品牌财报确认）
  ⑦ fetch_tmall_gmv（渠道销售确认）
  ⑥ causal_dag（品牌为什么砍单）
  ⑤ risk_assessor（工厂交期/产能影响）
  ④ scenario_predict（设计端是否调整）
  ③ fetch_kqindex（面料需求变化）
  ② fetch_pta_futures（化纤需求变化）
  ① fetch_world_bank（棉花需求变化预测）
  
  输出：整条链的需求萎缩传导报告
```

### 3.3 汇率变动跨环节评估

```
触发：JPY/USD 变化 >1.5%

追踪路径：汇率影响整条链的进出口环节
  ②化纤（进口原料成本）
  ⑤制造（出口收入）
  ⑥品牌（进口品牌成本/出口收入）
  ⑦渠道（进口商品零售价）
  ⑧消费者（购买力变化）
  
  Skills：fetch_fred_observation → causal_dag → scenario_predict → obsidian_writer
```

### 3.4 可持续趋势全链路响应

```
触发：Textile Exchange 发布新 GRS 标准

追踪路径：⑨回收→①农业→②化纤→③面料→⑤制造→⑥品牌→⑦渠道→⑧消费者
  ⑨ fetch_textile_exchange（新标准内容）
  ① fetch_world_bank（再生纤维对原棉需求影响）
  ② causal_dag（化纤厂是否需要调整产品线）
  ③ scenario_predict（面料厂能否承接再生面料）
  ⑤ risk_assessor（工厂是否需要认证）
  ⑥ websearch_品牌（品牌是否跟进）
  ⑦ websearch_消费者（消费者是否买单）
  
  输出：可持续趋势全链路影响评估
```

## 四、因果链条上的自进化

### 4.1 边的自学习

```
每条因果边的参数不是固定的，而是从数据中学习：

  边 ①→②（棉花→化纤传导率）：
    初始假设：传导率 0.7-0.9，滞后期 2 周
    实际观测：过去 12 个月的棉花价格 vs PTA 价格
    学习结果：传导率实际 0.82，滞后期 1.5 周
    更新：将学到的参数写入 causal_dag 的规则库
    
  边 ⑤→⑥（制造→品牌传导率）：
    初始假设：传导率 0.9-1.0，滞后期 3 月
    实际观测：过去 12 个月的工厂出厂价 vs 品牌零售价
    学习结果：传导率实际 0.75（品牌吸收了 25% 的成本上涨）
    更新：品牌利润被压缩 → 可能触发未来涨价
```

### 4.2 节点的自学习

```
每个环节的角色从使用中学习：

  采购经理（⑤制造环节）：
    过去 30 天使用了 47 次 causal_dag
    其中 32 次是"棉花价格→纱线成本→面料成本"的传导分析
    → 自动生成新技能：cotton_to_fabric_cost（棉花到面料成本传导计算器）
    → 合并 fetch_world_bank + fetch_pta_futures + fetch_kqindex + causal_dag
    → 成本降低 40%，延迟降低 60%
```

### 4.3 链的自学习

```
整条链的因果关系从全局数据中学习：

  发现：过去 6 个月，棉花价格涨 5% 时
    ②化纤价格涨 4%（传导率 0.8）
    ③面料价格涨 3%（传导率 0.75）
    ⑤成衣成本涨 2%（传导率 0.67）
    ⑥零售价涨 1%（传导率 0.5）
    
  模式：越往下游，传导率越低（品牌和渠道吸收了成本上涨）
  
  预测：如果棉花再涨 5%，零售端只会涨 1%
  
  行动：建议品牌方提前锁价（在传导链上游干预）
```

```

```
