# 回归验证结果（国统局真实数据）

> **数据**：2024-07 ~ 2026-05 月度数据
> **方法**：OLS 线性回归
> **关键发现**：大部分假设系数被数据推翻

---

## 回归结果汇总

| 测试 | 系数 β | R² | p 值 | 判定 |
|------|--------|-----|------|------|
| PPI纺织 → CPI衣着 | **0.068** | 0.047 | 0.401 | ❌ 不显著 |
| PPI总指数 → CPI衣着 | **0.013** | 0.011 | 0.686 | ❌ 不显著 |
| CPI衣着 → 零售额弹性 | **-6.87** | 0.354 | 0.012 | ✅ 显著 |

## 关键发现

### 发现 1：PPI→CPI 传导率极低（0.07）

```
之前假设：PPI 纺织涨 10% → CPI 衣着涨 3-5%
实际数据：PPI 纺织涨 10% → CPI 衣着涨 0.68%

原因分析：
  1. CPI 衣着包含服务（干洗/修改），不只是商品
  2. 品牌溢价变化吸收了成本上涨
  3. 渠道费用变化（电商费率/门店租金）
  4. 促销活动（折扣吸收成本）
  
结论：从工厂到消费者，成本传导被多层吸收
     出厂价涨 10%，零售价可能只涨 0.7%
```

### 发现 2：需求弹性 -6.87（比文献值高很多）

```
之前假设：需求弹性 = -0.50（文献值）
实际数据：需求弹性 = -6.87（回归值，p=0.012 显著）

含义：CPI 衣着涨 1% → 服装零售额降 6.87%

疑问：这个数字看起来很高。但数据确实显示：
  2025 年 CPI 衣着 +1.5% → 零售额 +2.8%（都涨了）
  2026 年 CPI 衣着 +1.8% → 零售额 +3.8%（都涨了）
  
  矛盾！如果弹性是 -6.87，CPI 涨 1.8% 应该导致零售降 12.4%
  但实际零售在涨！

原因分析：
  1. CPI 衣着包含服务（干洗/修改），零售额是商品
  2. 收入效应（人均可支配收入增长）在拉动需求
  3. 消费升级（买更贵的衣服）在拉动零售额
  4. 季节效应（春节/双 11）在干扰

结论：弹性 -6.87 不可信，但文献值 -0.50 也不确定
     需要更长的时间序列 + 控制收入效应
```

### 发现 3：能源传导几乎为零

```
PPI 燃料涨 10% → PPI 纺织涨 -0.2%

这与我们之前的加工费模型一致：
  能源占 FOB 仅 2.7%，不是主矛盾
  电力降价（PPI -4.4%）抵消了燃料涨价（PPI +10%）
  
结论：能源成本对纺织品价格的影响可以忽略
```

## 核心教训

```
1. 成本传导不是线性的
   工厂→批发→零售→消费者，每层都吸收一部分
   出厂价涨 10%，零售价可能只涨 0.7%（传导率 0.07）

2. 需求弹性比文献值大得多
   文献说 -0.5，实际可能 -5 到 -7
   但这个数字受收入效应干扰，不完全可信

3. 能源不是主矛盾
   PPI 燃料涨 10%，纺织品价格几乎不动
   电力降价抵消了燃料涨价

4. 真正的主变量是：
   原料成本（棉花/PTA）→ 通过加工费传导 → 到出厂价
   人工成本（年涨 5%）→ 直接影响加工费 → 到出厂价
   品牌溢价（动态）→ 吸收成本上涨 → 到零售价
```
